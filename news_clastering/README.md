# Система группировки и кластеризации новостей

## Что делает проект
- загружает новости
- очищает и лемматизирует текст
- превращает текст в TF-IDF признаки
- применяет алгоритмы кластеризации
- оценивает качество кластеризации
- отдает результат через API

## Шаг 1. Создать папку проекта
```bash
cd news_clustering
cd frontend

python run.py
npm run dev
